Third-party notices for the toml_document native Rust library

This file attributes the third-party Cargo dependencies of
adele_toml_document 0.1.0 in native/Cargo.lock. Coverage is the current
default-feature runtime/build dependency closure, checked with cargo tree
--locked and cargo tree --locked --edges normal,build from native/. The same
14 crate/version entries resolve for all targets configured in hook/build.dart:
x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu, x86_64-apple-darwin,
aarch64-apple-darwin, x86_64-pc-windows-msvc, and aarch64-pc-windows-msvc.

Lockfile-only packages outside the current runtime/build closure

native/Cargo.lock also records serde 1.0.229, serde_derive 1.0.229,
proc-macro2 1.0.107, quote 1.0.47, syn 3.0.7, and unicode-ident 1.0.26.
They are not active dependencies in the current default-feature native build.
The published serde_json and serde_core manifests contain cfg(any()) dependency
entries for serde and serde_derive respectively. That condition is always false;
cargo tree --target all includes these entries and their transitive dependencies
without establishing that they are compiled or linked for a real target.
