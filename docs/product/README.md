# Product Direction

Role: Intended product and user experience.

This category describes the behavior and UX ADELE aims to provide. Product
direction may deliberately be ahead of implementation; implementation progress
alone does not change the intended experience. Cross-system ownership and
invariants belong in architecture, even when they concern product concepts.
See the [documentation policy](../README.md) for authority and update criteria.
