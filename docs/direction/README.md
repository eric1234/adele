# Technical Direction

Role: Reviewed technical/design hypotheses.

These documents guide future work but remain explicitly less normative than
accepted architecture. They describe ADELE's best reviewed current hypotheses;
implementation pressure may legitimately change them without an architectural
reversal. Update them when the intended design changes, not merely when more of
it is implemented. See the [documentation policy](../README.md).

## Current contents

- [Agent tooling](agent-tooling.md): model-callable tools, execution, and presentation direction.
- [Stock plugin topology](stock-plugin-topology.md): reviewed hypothesis for default plugin division and composition.

New reviewed technical hypotheses belong in `docs/direction/`; accepted cross-system
constraints belong in [architecture](../architecture/).
